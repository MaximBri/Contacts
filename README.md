# Работа по переводу с чистого Redux на Redux Toolkit + RTK Query:

Всего есть 3 хранилища: контакты, группы, любимые контакты.

Слайсы с контактами и группами реализованы через `createApi`, любимые контакты через слайс `RTK` (они заполняются автоматически при получении группы контактов, берутся первые 4, реализация через `extraReducer`).

Слайсы расположены отдельно друг от друга, в соответствии с подходом `Re-ducks`

Данные контактов и групп размещены на `Mokky.dev`
